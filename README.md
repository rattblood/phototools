# เครื่องมือรูปภาพสำหรับงานพิมพ์ (Photo Tools)

เครื่องมือจัดรูปสำหรับพิมพ์ในหน้าเว็บเดียว ไม่ต้องติดตั้งโปรแกรม ไม่ต้องใช้อินเทอร์เน็ตหลังเปิดหน้าแล้ว ครอปรูปเป็น 4x6 นิ้ว จัดหลายรูปลงกระดาษ ทำรูปโพลารอยด์ และตัดรูปติดวีซ่า ส่งออกเป็น JPG 300 DPI

**เปิดใช้งาน:** `https://<ชื่อบัญชี>.github.io/<ชื่อ repo>/` (เปิดด้วย Chrome หรือ Edge)

## ความเป็นส่วนตัว

รูปทั้งหมดประมวลผลในเบราว์เซอร์ของคุณเท่านั้น **ไม่มีการอัปโหลดรูปไปที่ใดเลย** บน GitHub มีแค่ตัวโค้ดของเครื่องมือ

## แถบเครื่องมือ

| แถบ | ทำอะไร |
|---|---|
| **ครอป 4x6** | เปิดหลายรูปเป็นการ์ดเล็กๆ ครอปเป็น 4x6 นิ้ว (1200x1800 px, รูปแนวนอนได้ 1800x1200) ที่ 300 DPI |
| **borderless** | จัดรูปลงกระดาษ 4x6 นิ้ว แบบ 4 ช่อง (2x3 นิ้ว) หรือ 2 ช่อง (4x3 นิ้ว) |
| **polaroid** | รูปโพลารอยด์ 4 ใบต่อแผ่น 4x6 นิ้ว มีขอบขาวรอบรูป |
| **2P** | กระดาษ 3.5x6 นิ้ว (1050x1800 px) วางรูป 2 ใบ ขนาด 960x630 px ที่เหลือเป็นสีพื้น |
| **รูปติดวีซ่า** | ตัดรูปติดวีซ่า/รูปถ่ายบัตร และจัดลงแผ่นพิมพ์ |

## ฟีเจอร์หลัก

### แถบครอป 4x6
- ลากเพื่อเลื่อน หมุนล้อเมาส์เพื่อซูม ซูมออกจนรูปเล็กกว่ากรอบได้ ส่วนที่รูปไม่เต็มเติมด้วยสีที่เลือก
- แนวกรอบตามรูปอัตโนมัติ รูปจัตุรัสกดปุ่ม ⟳ เลือกแนวเอง
- ป้ายเตือน ⚠ เมื่อรูปถูกขยายจนความละเอียดต่ำกว่า 300 DPI
- Export รูปที่เลือก หรือทั้งหมด

### แถบ borderless / polaroid / 2P
- เห็นทั้งแผ่นกระดาษบนจอ ลากและซูมรูปในแต่ละช่อง
- **หมุนกระดาษ ⟳:** หมุนทั้งแผ่น 90° รูปแนวตั้ง/แนวนอนใช้ได้ทั้งคู่ (ไฟล์ที่ได้เป็นแนวนอน)
- **เส้นตัด:** วางตามรอยต่อระหว่างช่อง เปิด/ปิดได้
- **แบ่งแผ่นอัตโนมัติ:** ใส่หลายสิบรูปได้ โปรแกรมแบ่งเป็นหลายแผ่นให้ ใช้ ◀ ▶ หรือปุ่มลูกศรบนคีย์บอร์ดสลับแผ่น มีปุ่มย้ายรูป ลบรูป แทนรูป
- **ซ้ำรูปเดียวทั้งแผ่น:** ติ๊กแล้ว 1 รูป = 1 แผ่น รูปเดียวกันเต็มทุกช่อง
- Export แผ่นนี้ หรือทุกแผ่น ชื่อไฟล์เรียงลำดับ เช่น `polaroid_20261106001805_01.jpg`
- **polaroid:** ขอบเริ่มต้นบน 0.6 ซม. ข้าง 0.4 ซม. ล่าง 1.31 ซม. (ช่องรูป 3:4) แก้ตัวเลขได้
- **2P:** ตำแหน่งตามแบบ ขอบซ้ายขวา 45 px ขอบบน 41 px ช่องว่างระหว่างรูป 62 px

### ปรับสีและแสง (แถบครอป และแถบจัดหน้าทุกแถบ)
Levels (พร้อม Histogram และ Auto Levels), Curves, Shadows/Highlights, Color Balance (โทนกลาง, Preserve Luminosity), Saturation, Vibrance

- ปรับแยกรายรูป แผงอยู่ด้านขวา
- ปุ่ม "ใช้ค่านี้กับทุกรูป/ทุกช่อง" และคัดลอก/วางค่าสี (ไม่รวมตำแหน่ง crop)
- ปุ่มกดค้างเพื่อเทียบก่อนปรับ ดับเบิลคลิกสไลเดอร์เพื่อรีเซ็ตค่านั้น
- ปรับเฉพาะส่วนที่เป็นรูป สีพื้น ขอบ และเส้นตัดไม่ถูกปรับตาม

## การส่งออก

- JPG เท่านั้น ปรับคุณภาพได้ (ค่าเริ่มต้น 95) ฝัง 300 DPI ในไฟล์
- **Chrome/Edge:** กด "เลือกโฟลเดอร์เซฟ" เพื่อบันทึกลงโฟลเดอร์ที่ต้องการโดยตรง (ต้องเลือกใหม่ทุกครั้งที่เปิดหน้า)
- เบราว์เซอร์อื่น หรือถ้าไม่เลือกโฟลเดอร์: ดาวน์โหลดลงโฟลเดอร์ Downloads ถ้าเซฟหลายไฟล์ Chrome อาจถามขออนุญาตดาวน์โหลดหลายไฟล์ ให้กดอนุญาต

## ข้อจำกัด

- สี **sRGB เท่านั้น** ไฟล์ที่ส่งออกไม่ฝัง ICC profile ไม่มี CMYK และไม่มี soft-proof
- เปิดได้เฉพาะ JPG, PNG, WebP ไม่รองรับไฟล์ RAW และ HEIC
- รูปจำนวนมากใช้แรมมาก (ราว 30 รูป จากกล้องความละเอียดสูง ใช้แรมประมาณ 0.8 GB) ถ้าเครื่องช้าให้แบ่งทำเป็นรอบ
- เลือกโฟลเดอร์เซฟและ Eyedropper (ดูดสี) ใช้ได้เฉพาะ Chrome/Edge
- **ตอนพิมพ์:** พิมพ์ที่ขนาดจริง 100% และปิด "Fit to page" ไม่เช่นนั้นเครื่องพิมพ์อาจย่อหรือครอบภาพ ทำให้ขอบและเส้นตัดเพี้ยน

## วิธีเอาขึ้น GitHub Pages

1. สร้าง repository แบบ **Public** บน github.com
2. อัปโหลดไฟล์ `index.html` (ชื่อตัวพิมพ์เล็กตามนี้) และ `README.md`
3. ไปที่ Settings > Pages เลือก "Deploy from a branch" แล้วเลือก branch `main` โฟลเดอร์ `/ (root)` กด Save
4. รอ 1-2 นาที จะได้ลิงก์ใช้งาน
5. อัปเดตเวอร์ชันใหม่: อัปโหลดไฟล์ `index.html` ตัวใหม่ทับชื่อเดิม แล้ว Commit (ถ้ายังเห็นของเก่า กด Ctrl+F5)

## โครงสร้างไฟล์

ทุกอย่างอยู่ใน `index.html` ไฟล์เดียว แต่ละแถบทำงานแยกกันภายในหน้า สลับแถบแล้วงานที่ค้างไว้ไม่หาย
